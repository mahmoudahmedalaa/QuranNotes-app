# Noor RAG Guides

Permanent operator/learning references for the QuranNotes Noor RAG implementation.

## Files

- `QuranNotes_Noor_RAG_Visual_Guide.html` — standalone interactive browser guide with architecture, configuration, verification layers, project-console links, and RAG learning notes.
- `QuranNotes_Noor_RAG_Executive_Technical_Guide.html` — concise executive technical reference suitable for browser/printing.
- `QuranNotes_Noor_RAG_Executive_Technical_Guide.doc` — Word-compatible document version of the executive guide.

## Maintenance rule

Update stable production identifiers in these guides only after a newer candidate passes authenticated end-to-end live verification and is promoted as the stable Noor baseline.

The current documented safe baseline is `noor-rag-stable-v1`; candidate work is intentionally not represented as production until live verification passes.
